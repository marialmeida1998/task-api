# Template de Prompt — Análise de Requisitos

## Título da resposta
Análise de Requisitos – Recomendação de Artefatos de Especificação

## Instruções gerais
Baseie todas as recomendações exclusivamente nas histórias de usuário identificadas no projeto. Não invente funcionalidades nem requisitos adicionais. Considere o contexto real do sistema, sua complexidade e os artefatos de Engenharia de Requisitos mais adequados para apoiar a especificação.

## Estrutura obrigatória da resposta

### 1. Tabela de artefatos
Apresente uma tabela com a seguinte estrutura:

| Artefato | Recomenda? | Prioridade | Justificativa |
|---|---|---|---|

Inclua os artefatos abaixo, quando aplicáveis ao projeto:
- Critérios de Aceitação
- Casos de Uso
- Matriz de Perfis e Permissões (RBAC)
- Especificação de Requisitos Não Funcionais
- Protótipos
- Diagrama de Casos de Uso
- Diagrama de Sequência UML
- Matriz de Rastreabilidade
- DER
- BPMN
- Diagrama de Estados

### 2. Explicação detalhada dos artefatos recomendados
Explique, de forma objetiva e profissional, por que os artefatos recomendados são adequados ao projeto, considerando as histórias de usuário analisadas.

### 3. Artefatos não priorizados e seus motivos
Liste os artefatos que não devem ser priorizados no momento e justifique cada decisão com base nas histórias de usuário e no contexto do projeto.

### 4. Se eu pudesse escolher apenas dois artefatos
Indique os dois artefatos mais importantes para este projeto e explique por que eles devem ser produzidos primeiro.

### 5. Recomendação resumida — próximos passos
Informe, de forma resumida, quais artefatos devem ser produzidos primeiro e em qual ordem de prioridade.
